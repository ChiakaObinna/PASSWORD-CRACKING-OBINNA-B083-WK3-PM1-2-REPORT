📌 Project Overview
This project documents my Week 3 cybersecurity practical focused on password auditing and recovery of an authorized password-protected PDF.
The lab followed a workflow that included:
Generating a hash representation of the PDF using Online HashCrack.
Using the Networkwalks Hash Calculator during the hash-generation/handling stage.
Installing and preparing John the Ripper (JTR) on Windows.
Processing the generated hash through the Networkwalks Password Cracker.
Successfully recovering the password for the authorized lab PDF.
Capturing evidence of the activities for documentation and portfolio purposes.
> **Important:** The exact recovered password is intentionally not published in this repository.

---

🎯 Objectives
Understand the role of hashes in password auditing.
Generate a hash representation from a password-protected PDF.
Prepare John the Ripper on Windows for password-auditing practice.
Work with the Networkwalks Hash Calculator.
Use the Networkwalks Password Cracker as part of the recovery workflow.
Verify successful recovery of the protected PDF password.
Document the complete practical process with evidence.
